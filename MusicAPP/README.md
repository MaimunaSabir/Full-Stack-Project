# MusicAPP

A Spotify-inspired music application built using the MERN stack.

## Features

- User Authentication
- Artist Authentication
- Upload Music
- Create Albums
- View Music
- View Albums
- Play Songs
- Responsive Design

## Technologies

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- ImageKit

## How to Run

### Backend

cd Backend
npm install
npm start
### Frontend
cd Frontend
npm install
npm run dev
